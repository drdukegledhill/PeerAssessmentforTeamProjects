Peer Assessment Report v1.9

Upload a peer assessment CSV to instantly generate normalised scores and individual feedback — everything runs in your browser, no data is uploaded anywhere.

Select your peer assessment CSV file

Exported from Google Sheets: File → Download → Comma Separated Values (.csv)

How to Use

  1. Set up a peer assessment Google Form (see Setting Up Google Forms below) and collect responses.
  2. Open the linked Google Sheet, then go to File → Download → Comma Separated Values (.csv).
  3. Click Select your peer assessment CSV file above and choose the downloaded file.
  4. The report generates instantly — normalised scores, summary table, and individual feedback with peer comments.
No installation required. Your data never leaves your browser — all processing happens on your device.

Setting Up Your Form

Create a Google Form with the following questions:

  1. Dropdown question: “Select your name” — add all team member names as options.
  2. For each team member, add two questions:
    • Linear scale (1–9): “Please rate overall contribution from [Name]”
    • Short answer: A justification question, e.g. “Justify your rating for [Name]”
  3. Link responses to a Google Sheet: in Google Forms, go to the Responses tab and click the Sheets icon.
  4. When data collection is complete, in Google Sheets go to File → Download → Comma Separated Values (.csv).
Tip: The justification question text doesn’t matter — the tool uses the column immediately after each “overall contribution” column.

Create a Microsoft Form at forms.office.com with the following questions:

  1. Choice question: “Select your name” — add all team member names as options. Set to allow one answer (dropdown).
  2. For each team member, add two questions:
    • Choice question with options 1, 2, 3 … 9: “Please rate overall contribution from [Name]”. Set to allow one answer (dropdown).
    • Text question: A justification question, e.g. “Justify your rating for [Name]”
  3. Share the form with your team and collect responses.
  4. When data collection is complete, go to the Responses tab and click Open in Excel. Then in Excel go to File → Save As → CSV UTF-8 (.csv).
Tip: Use a Choice question (not Rating) for the 1–9 scores — this ensures values export as plain numbers. Include “Select your name” even if your form requires sign-in, as the tool uses this column to exclude self-assessments.

How Normalisation Works

Raw peer scores are adjusted so that the group centres on 5, enabling fair comparison across teams with different rating tendencies (e.g. a generous team vs. a harsh team):

  1. All peer scores are collected, excluding self-assessments (a student’s own rating of themselves).
  2. Each student’s raw average is calculated from the scores they received.
  3. Any student who received all zeros from every peer rater is flagged as Did not attend (DNA) and excluded from the normalisation reference. Their score is recorded as 0.
  4. The median of the remaining students’ raw averages is used as the group reference point. The median is used rather than the mean so that one very low-scoring student does not distort everyone else’s scores.
  5. An adjustment is applied: normalised = raw average + (5 − group median)
  6. Results are rounded using banker’s rounding (round half to even) and clamped to the 0–9 range.
A team that rates generously will be adjusted down; a harsh team adjusted up. Each student’s final score reflects their standing relative to their group, not the group’s absolute rating level.

Python CLI Version

A command-line version is also available for batch processing or scripted workflows. It produces identical output to this web tool and requires only Python 3.6+ with no external dependencies.

python3 pa_report.py "team1.csv"
